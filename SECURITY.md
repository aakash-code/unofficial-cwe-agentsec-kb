# Security policy

## Supported release

The `main` branch is the supported development release until versioned releases
are published.

## Reporting a vulnerability

Do not disclose vulnerabilities in this repository, its release process, or
its MCP server through a public issue. Contact the maintainers through the
private reporting address published with a release. Until one is configured,
open a minimal issue asking for a private contact channel and do not include
technical details.

Include:

- affected version or commit;
- reproduction steps using only safe, local materials;
- impact and suggested mitigation;
- whether you want public credit.

We aim to acknowledge valid reports within seven days, provide a status update
within 30 days, and coordinate a fix before public disclosure when practical.

## Safe operation

The bundled reviewer and MCP server are intended for local repository analysis
only. They do not need credentials or network access. Do not configure them to
run untrusted code or against systems outside your authorization.
