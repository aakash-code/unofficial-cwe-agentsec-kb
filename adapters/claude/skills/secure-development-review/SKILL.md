---
name: secure-development-review
description: Provide authorized, evidence-led secure code reviews using AgentSec KB rules and safe remediation guidance.
---

Before reviewing code, establish authorized scope and use non-destructive local
methods by default. Consult the AgentSec KB rule matching the risk before
reporting it. Return evidence, severity, confidence, CWE references, safe local
verification, remediation, and limitations. Redact sensitive values and never
provide intrusive testing or exploitation instructions.
