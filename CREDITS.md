# Credits

AgentSec KB is built on original project guidance and the work of the broader
application-security community. We thank the following organizations and
communities for the public standards and references that inform this project.

## Common Weakness Enumeration (CWE™)

This project includes the complete official Common Weakness Enumeration (CWE™)
4.20 XML distribution, maintained by The MITRE Corporation, and derived JSON
representations that preserve its content. CWE is a trademark of The MITRE
Corporation. Use of CWE content is subject to the [CWE Terms of Use](https://cwe.mitre.org/about/termsofuse.html).

## OWASP Foundation

This project links to OWASP guidance. OWASP materials are used only when their
license and attribution requirements can be met. Unless a file states
otherwise, this repository does not reproduce OWASP text. See the [OWASP
disclaimer and licensing information](https://owasp.org/www-policy/operational/general-disclaimer).

## National Institute of Standards and Technology (NIST)

This project references the [Secure Software Development Framework
(SSDF)](https://csrc.nist.gov/projects/ssdf), including NIST SP 800-218 and
related guidance, as informative secure-development references. NIST does not
endorse this project.
